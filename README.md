
# Arx2V - The Hardware Description Language for Humans and AI
![Arx Demo](demo.gif)


**Arx** is a new Hardware Description Language (HDL) designed to be intuitive for visual architects and safe for AI-generated code. **Arx2V** is its compiler - a single Python file (no LLVM, no Scala, no C++) that translates Arx into clean, synthesizable Verilog-2001.

## Why Arx?

Verilog is from the 80s. It forces you to think like a wire-plumber, and its silent bugs (width truncation, multiple drivers, latch inference) cost the industry millions.

Arx fixes this with:

- **Human-first syntax**: `behavior on comb:`, `when`, `connect`, `lock` instead of `always @(*)`, `case`, `wire`.
- **AI-safe guardrails**: a strict Type Checker catches width mismatches and multiple drivers *before* generating Verilog.
- **Zero dependencies**: pure Python 3.8+. Runs on a phone.
- **Testbench generator**: `generate testbench for <file.arx>` creates the Verilog TB automatically.

Quick Example: 32-bit ALU

Input (alu.arx):

```arx
module alu
input:
    a [32 bits]
    b [32 bits]
    alu_op [3 bits]
output:
    result [32 bits]
wires:
    sub_res [32 bits]
logic:
    connect sub_res = a - b
    connect result = mux(alu_op)
        (a + b),
        sub_res,
        (a bitwAnd b),
        (a bitwOr b),
        (a bitwXor b),
        (sub_res[31] + 0),
        0,
        0 fallbackVal: 0
end module
```

Output (generated Verilog):

```verilog
module alu (
  input [31:0] a, input [31:0] b, input [2:0] alu_op,
  output [31:0] result
);
  wire [31:0] sub_res;
  assign sub_res = (a - b);
  assign result = (alu_op == 3'd0) ? (a + b) :
                  (alu_op == 3'd1) ? sub_res :
                  (alu_op == 3'd2) ? (a & b) :
                  (alu_op == 3'd3) ? (a | b) :
                  (alu_op == 3'd4) ? (a ^ b) :
                  (alu_op == 3'd5) ? (sub_res[31] + 32'd0) :
                  (alu_op == 3'd6) ? 32'd0 :
                  (alu_op == 3'd7) ? 32'd0 : 32'd0;
endmodule
```
